# I Feel Like Chocolate Today: SPSS guide

Step-by-step guide for the IÉSEG Data Insights SPSS group project: data cleaning, summated scales, health concern segments and the six research questions, with the menu clicks, the reason for each step and how to read the output.

- `index.html`: the guide (open it in a browser, or use the GitHub Pages link)
- `chocolate_project_syntax.sps`: the same steps as SPSS syntax

The dataset itself is not included.
