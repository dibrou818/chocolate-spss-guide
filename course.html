PART A · A1 · Session 1Variable View: name, label, values, measure

Session 1: SPSS can only analyse numbers, and the numbers need a meaning. The Variable View holds that meaning: what each variable is (label), what each code means (values) and what kind of data it is (measure), which decides the test you may use.

1

Open, save a copy, go to Variable View

  1. File›Open›Data… → Dataset Group Project SPSS.sav → Open (S1, step 1–2).
  2. File›Save As… → … CLEANED.sav. This is the file you send at the end.
  3. Click the Variable View tab (bottom-left).
If no output appears later (S1 troubleshooter)

If “OMS” shows at the bottom of the window: File›New›Syntax, type OMSEND., select it, click the green ▶, then rerun your analysis.

2

Names and labels

S1 rule for names: no symbols like “-”, no spaces, do not start with a number. The label has no restrictions and is the full description that appears in the output.

  1. Name column: double-click, type, Enter. Rename the codes that mean nothing: q42 → gender, q4301 → age, q44 → living, q46 → education, q47 → occupation, q48 → native_lang, q49 → province, q50 → area. The other names (feel, freq, att, f04–f07, mot, g) match the instructions, so keep them.
  2. Label column: type the survey question for every variable, e.g. feel1 “Eat chocolate when feeling: Happy”, f0603 “Buy: vending machine”, mot3 “Why: to kill hunger between meals”.

The list of all labels is on the full guide, step A1.3.

3

Value labels (S1 rule: “values are tied to measurement levels”)

S1: categorical variables (nominal, ordinal) get a label for every category. Invented metric scales (Likert, semantic differential) get labels on the end-points only. Natural scales (age, number of people) get no labels.

  1. Values cell → blue … box → Value 1, Label Male → Add → 2 Female → Add → OK.
  2. Copy a finished Values cell (right-click › Copy) and paste it on the other variables with the same scale.

S2 rules for removing items

Items must be phrased in the same direction (recode if needed). Minimum 3 items, maximum 10. If α only increases slightly when an item is deleted, keep it: only remove an item if α would move to another level. If you remove an item from the scale, do not delete it from the dataset.

1

Recode g4 and g5 by mirroring

g1–g3 (worried, guilty, ashamed): a high score = high concern. g4–g5 (very satisfied, full of joy): a high score = low concern. They are phrased in the other direction, so S2 says: recode them so that 7 means the same thing for every item.

  1. Transform›Recode into Different Variables…
  2. Click g4 → arrow. Output Variable: Name g4_recoded, Label “After eating: very satisfied/happy (recoded)” → Change.
  3. Do the same for g5 → g5_recoded (both can be in the same dialog).
  4. Old and New Values… → first: System- or user-missing → System-missing → Add.
  5. Then: 1 → 7, 2 → 6, 3 → 5, 4 → 4, 5 → 3, 6 → 2, 7 → 1 (Add each time) → Continue → OK.
  6. Check in Data View that a 2 in g4 is now a 6 in g4_recoded. Variable View: Measure Scale, value labels 1 = Almost always, 7 = Never (the labels are mirrored too).

Report

We recoded “very satisfied/happy” and “full of joy” after eating chocolate by mirroring them (1 = almost always – 7 = never instead of 1 = never – 7 = almost always).

1. Choose the test (S5 decision tree)

2. Write the hypotheses (S4 structure)

H1 = cause → effect, a specific DV, a benchmark in the IV (“than…”), a clear direction (more / less), testable. H0 = same structure but “equal / the same / similar” (not “not bigger”).

3. Select respondents when needed (S2)

  1. Data›Select Cases… → If condition is satisfied → If… → seg = 1 → Continue → OK.
  2. Check quickly in Data View that the right rows are selected (others are crossed out).
  3. After the analysis: Data›Select Cases → All cases → OK (or delete the filter variable). Report the selection with its coding (e.g. “seg = 1”).

4. Read significance and effect size (S4, S5)

  • Always read the two-sided significance. p ≤ .050 → significant, H0 rejected. p > .050 → not significant: say the groups are equal in the population, never that one is higher.
  • Only if significant: look at the means (direction) and the effect size (size). Tick Estimate effect sizes in every t-test and ANOVA dialog.

Conclusion in plain words

Compared with the low-concern segment, highly concerned consumers are more often women, younger (31 vs 39 years), more often students living with their parents, and eat chocolate more for pure indulgence and when lonely. Chocolate fits better for them at almost every moment, especially late at night and after dinner (where they also beat the medium segment). They buy more in impulse channels (vending machines, bookshops, petrol stations and above all night shops), not more in supermarkets. All effects are small (η² ≤ .09, Cramer's V ≤ .15).
