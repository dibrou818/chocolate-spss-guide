# I Feel Like Chocolate Today: SPSS guide

Step-by-step guide for the IÉSEG Data Insights SPSS group project: data cleaning, summated scales, health concern segments and the six research questions, with the menu clicks, the reason for each step and how to read the output.

- `index.html`: the full guide (open it in a browser, or use the GitHub Pages link)
- `course.html`: the project solved with course methods only
- `revision.html`: revision sheet for the exam
- `qcm.html`: MCQ practice
- `report.html`: how to write the report, with example text
- `slides.html`: how to build the presentation slides
- `steps.html`: the whole project in SPSS click by click, with the predicted output of every step
- `chocolate_project_syntax.sps`: the same steps as SPSS syntax

The dataset itself is not included.
